# Streak

Wochen-Streaks für eigene Ziele. Jedes Ziel hat ein Minimum pro Woche (Mo–So). Wer es schafft, verlängert die Streak.

## Regeln

- Woche geschafft: Streak +1, eine Verwarnung verschwindet.
- Woche verpasst: Verwarnung, die Streak bleibt stehen.
- Verwarnt und eine Woche ganz ohne Eintrag: Streak auf 0.
- Ein Eintrag nach der verpassten Woche hebt die Verwarnung auf.
- Die Woche, in der ein Ziel angelegt wird, zählt nur, wenn sie geschafft wird.
- Ein Tag endet erst um 3 Uhr nachts.
- Pausierte Wochen bringen weder Verwarnung noch Reset.
- Einträge über dem Minimum zählen als Bonus.

## Speicher

Die App ist eine einzelne Datei (`index.html`). Als Claude-Artifact speichert sie im Claude-Konto. Direkt im Browser geöffnet (z. B. über GitHub Pages) speichert sie nur lokal im Browser. Umziehen geht über „Backup speichern“ und „Backup laden“.
